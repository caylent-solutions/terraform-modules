# dynamodb-table

AWS DynamoDB table primitive Terraform module.

Ships:

- `aws_dynamodb_table` with full attribute, key, and index control:
  - Partition + optional sort key (with attribute definitions)
  - Variadic Global Secondary Indexes (GSI) and Local Secondary Indexes (LSI)
  - PAY_PER_REQUEST (on-demand) or PROVISIONED billing modes
  - DynamoDB Streams (`stream_enabled` + `stream_view_type`)
  - TTL (`ttl_attribute_name`)
  - Point-in-time recovery (PITR; default on)
  - Server-side encryption (always on; customer-managed KMS via `kms_key_arn`)
  - `STANDARD` or `STANDARD_INFREQUENT_ACCESS` table class
  - `deletion_protection_enabled`
- Optional Application Auto Scaling for table-level read and write
  capacity (`autoscaling_enabled = true`, PROVISIONED billing only)
  with target-tracking policies.

Cross-variable validation enforces invariants at plan time:

- `billing_mode = PROVISIONED` requires `read_capacity > 0` AND `write_capacity > 0`.
- `autoscaling_enabled = true` requires `billing_mode = PROVISIONED`.

## Usage

```hcl
module "table" {
  source = "git::https://github.com/caylent-solutions/terraform-modules.git//providers/aws/primitives/dynamodb-table?ref=providers/aws/primitives/dynamodb-table/v0.1.0"

  name      = "telemetry-events"
  hash_key  = "pk"
  range_key = "sk"

  attributes = [
    { name = "pk",     type = "S" },
    { name = "sk",     type = "S" },
    { name = "gsi1pk", type = "S" },
  ]

  global_secondary_indexes = [
    {
      name            = "gsi1"
      hash_key        = "gsi1pk"
      projection_type = "ALL"
    },
  ]

  stream_enabled     = true
  stream_view_type   = "NEW_AND_OLD_IMAGES"
  ttl_attribute_name = "expires_at"

  point_in_time_recovery_enabled = true
  deletion_protection_enabled    = true

  tags = {
    Application = "telemetry"
    Environment = "prod"
  }
}
```

For a runnable example see [`examples/basic/`](examples/basic/README.md).
