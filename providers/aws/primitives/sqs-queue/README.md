# sqs-queue

AWS SQS queue primitive Terraform module.

Ships:

- A primary SQS queue (standard or FIFO) with full attribute control:
  delay, max message size, message retention, long-poll wait, visibility
  timeout, and either a customer-managed KMS key or AWS-managed SSE-SQS
  encryption.
- An optional dead-letter queue (`create_dlq = true`) wired via a
  redrive policy on the primary queue. The DLQ defaults to 14-day
  retention for forensic investigation.
- An optional CloudWatch metric alarm on `ApproximateNumberOfMessagesVisible`
  for the DLQ (`create_dlq_depth_alarm = true`) with configurable
  threshold, evaluation periods, and SNS topic ARNs for ALARM and OK
  notifications.

The module enforces SQS limits via Terraform variable validation
(`message_retention_seconds`, `visibility_timeout_seconds`,
`receive_wait_time_seconds`, `max_message_size`, etc.) so misconfiguration
is rejected at plan time.

## Usage

```hcl
module "queue" {
  source = "git::https://github.com/caylent-solutions/terraform-modules.git//providers/aws/primitives/sqs-queue?ref=providers/aws/primitives/sqs-queue/v0.1.0"

  name                       = "telemetry-ingest"
  visibility_timeout_seconds = 60
  message_retention_seconds  = 1209600

  create_dlq        = true
  max_receive_count = 5

  create_dlq_depth_alarm    = true
  dlq_depth_alarm_threshold = 10
  dlq_depth_alarm_actions   = [aws_sns_topic.alerts.arn]

  tags = {
    Application = "telemetry"
    Environment = "prod"
  }
}
```

For a runnable example see [`examples/basic/`](examples/basic/README.md).

## Encryption

- When `kms_master_key_id` is set, the queue uses customer-managed KMS
  encryption with a configurable data-key reuse period
  (`kms_data_key_reuse_period_seconds`).
- When `kms_master_key_id` is null and `sqs_managed_sse_enabled` is true
  (default), the queue uses AWS-managed SSE-SQS encryption.
- The two are mutually exclusive at AWS; the module enforces this by
  conditionally setting `sqs_managed_sse_enabled` only when no
  customer key is provided.

## FIFO

Set `fifo_queue = true` to create a FIFO queue. The module appends the
required `.fifo` suffix to both the primary queue name and the DLQ name
(when enabled). Toggle `content_based_deduplication` independently.
